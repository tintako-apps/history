# Files

> **No longer developed.** Files 1.0 is the last version. All versions are kept here in History: [releases](RELEASES.md).

A quiet file manager made for E Ink: your music, books, pictures and downloads as simple folders, with move, rename and a bin that keeps deleted files for 30 days.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/tintako)

## What it can do
- Start screen with the phone's folders first (Music, Books, Pictures, Apps, Downloads, Documents…), then your own folders, then the Bin
- Touch a file to open it in the app that reads it, for example a book in Books or an event file in Calendar
- Hold a file or folder to move, rename or delete it
- Make a new folder anywhere with the black +
- Deleted files wait 30 days in the Bin, where you can restore them or delete them for good
- Choose the order of files in a folder: name, newest or size; folders always come first
- Show or hide hidden files
- Lists turn page by page, with the arrows or the volume keys

**Languages:** Croatian, English, German, French, Spanish, Italian, Portuguese, Dutch, Polish, Czech

## Good to know
- Files never sets itself as the default app; the phone asks which app opens each file type
- Nothing runs in the background; old items leave the Bin when you open the app

## Permissions
- All files access: to show your folders and to move, rename and delete what you choose. Files has no internet permission and sends nothing anywhere.

## Privacy
Fully offline. No accounts, no ads, no analytics and no tracking. See [PRIVACY.md](PRIVACY.md), [TERMS.md](TERMS.md) and [LICENSES.md](LICENSES.md).
